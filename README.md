## 🚀 Guía de Inicio para el Equipo

### 1. Clonación y Configuración
Para comenzar, clona el repositorio y muévete a tu rama asignada. **No trabajes en la rama `main`**.

```bash
# Clonar
git clone [https://github.com/TU_USUARIO/SetMaster-Compiler.git](https://github.com/JoshGab05/SetMaster-Compiler.git)
cd SetMaster-Compiler

# Ir a tu rama (Elige la tuya)
git checkout feature/lexico
git checkout feature/sintaxis
git checkout feature/logica-semantica
git checkout feature/venn-visualizacion
